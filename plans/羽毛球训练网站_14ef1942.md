# 羽毛球训练网站（Badminton Fit）实施计划

## 1. 工程与 GitHub 配置
- **栈**：pnpm、Vite 6、React 19、TypeScript（strict）、Tailwind CSS v4（`@tailwindcss/vite`，`dark` 用 class 变体）、React Router v7 **Hash 模式**（兼容 GitHub Pages 子路径与单 HTML `file://` 打开）、zustand（`persist` 中间件存 localStorage）、fuse.js（全局搜索）、vitest（数据校验测试）。
- **ESLint**：`@antfu/eslint-config`（开启 `react: true`、`typescript: true`），不使用 Prettier；`.vscode/settings.json` 配置 `editor.codeActionsOnSave: source.fixAll.eslint` 保存自动修复，`.vscode/extensions.json` 推荐 ESLint、Tailwind 插件。
- **Git 钩子**：`simple-git-hooks` + `lint-staged`，提交前 `eslint --fix`。
- **仓库文件**：`.gitignore`、`.editorconfig`、`.nvmrc`(22)、`package.json` 中 `packageManager` 与 `engines`、`README.md`（功能、开发命令、两种构建说明、资料来源声明）、`LICENSE`(MIT)。
- **GitHub Actions**：
  - `ci.yml`：PR/push 时 install → lint → typecheck → test → build（两种产物）。
  - `deploy.yml`：push 到 `main` 时构建多文件版并部署 GitHub Pages（`actions/deploy-pages`），同时上传单 HTML 为 artifact；打 `v*` tag 时把单 HTML 附加到 Release。
- `vite.config.ts` 使用 `base: './'`，无需写死仓库名。

## 2. 两种构建产物
- `pnpm build`：常规多文件产物 → `dist/`，启用 `vite-plugin-pwa`（Service Worker 预缓存，可安装到桌面）。
- `pnpm build:single`：`--mode single`，启用 `vite-plugin-singlefile`，关闭 PWA 与代码分割，所有 JS/CSS/SVG/字体内联 → `dist-single/index.html`。
- 所有图片均为代码绘制的 SVG 组件，无外部图片资源；B 站视频为 iframe 外链（离线时显示占位提示和跳转链接）。
- 图标字体不引入外部 CDN，图标用内联 SVG（如 `lucide-react` 按需引入）。

## 3. 目录结构
```
src/
  app/            路由、布局、主题、搜索面板
  pages/          Home / Muscles / MuscleDetail / Exercises / ExerciseDetail / Plans / PlanDetail / PlanEditor / Checkin / Stats / About(资料来源)
  components/
    body/         BodyMap(三视角 SVG)、MuscleRegion、ViewSwitcher
    figure/       PoseFigure(参数化人形 SVG)、PoseAnimator(起止姿态插值动画)
    video/        BiliPlayer(懒加载 iframe + 离线兜底)
    ui/           Card、Tag、Dialog/Drawer、Tabs、Badge 等
  data/
    muscles.ts    肌肉数据
    exercises.ts  训练动作数据（按类别拆分文件）
    poses.ts      动作姿态关键点
    techniques.ts 羽毛球技术（杀球、跨步救球、启动步、头顶球等）
    plans.ts      预设计划
    sources.ts    参考文献清单
  store/          plans、checkins、settings（zustand persist，带版本号与迁移）
  utils/          日期、导入导出、统计
  types/
tests/            数据完整性测试
```

## 4. 数据模型（核心，三者双向关联）
- **Muscle**：`id`、中文名/英文名/拉丁学名、所属区域（肩/上臂/前臂/胸/核心/背/臀/大腿/小腿）、视角与 SVG 区块 id、起止点、主要功能、**羽毛球中的作用**（关联 `techniqueIds`）、常见损伤与预防、`exerciseIds`（由动作反向计算，无需手写）、`sources`。
- **Technique**：羽毛球技术动作（正手高远/杀球、反手、网前搓放、跨步上网、后场起跳、侧向蹬转、启动分腿步等），列出主动肌/协同肌，引用 EMG/生物力学文献。
- **Exercise**：`id`、中英文名、类别、难度、器械、`primaryMuscles`/`secondaryMuscles`、对羽毛球的益处（关联技术）、步骤、要点、常见错误、进阶/退阶变式、推荐组数次数（按难度）、`poses`（起止姿态）、`bilibili`（BV 号 + 标题 + 来源 UP 主）、`sources`。
- **Plan**：难度（入门/进阶/高阶）、单次时长（约 20/40/60 分钟）、周期（4/8 周）、每周天数、每天的动作列表（组数/次数/时长/休息）。
- **Checkin**：日期、planId、dayIndex、完成的动作及实际组数、主观疲劳度 RPE、备注。

## 5. 内容资料来源（不胡编）
实施时先联网检索，每条肌肉/动作数据标注引用：
- 解剖：Kenhub、TeachMeAnatomy、Physiopedia、StatPearls(NCBI)。
- 动作规范：ACE Exercise Library、NSCA、ExRx 等。
- 羽毛球专项：BWF Shuttle Time 教练手册、PubMed 上羽毛球跨步/杀球的 EMG 与生物力学研究、运动损伤综述。
- 视频：在 B 站检索官方或专业来源（BWF 官方、体能教练/康复师账号、专业运动医学机构），**逐个核实 BV 号**；找不到可靠视频的动作不硬塞，改为显示"在 B 站搜索该动作"链接。
- `About` 页面集中列出全部参考文献，并声明内容仅供参考，不构成医疗建议。

## 6. 肌肉图解模块
- 代码自绘风格化人体 SVG，**正面 / 背面 / 侧面**三视角切换（Tab + 键盘左右切换），约 30–40 块可点击肌肉区块；深层肌肉（臀中肌、髂腰肌、肩袖四肌、腹横肌、胫骨前肌等）在对应视角用虚线轮廓或"深层肌肉"列表补充。
- 交互：hover 高亮 + tooltip 显示名称；点击弹出详情抽屉（移动端底部弹层）：基本信息、在羽毛球中的作用、用到它的技术、锻炼它的动作（卡片可跳转）、损伤预防、参考来源；可跳转独立详情页（可分享链接）。
- 侧栏按身体区域筛选；从动作页跳回时，图中高亮对应肌肉。
- 无障碍：区块带 `role="button"`、`aria-label`，支持 Tab 聚焦与回车打开。

## 7. 训练方法模块
- 约 60 个动作，分类：
  - **下肢力量**：保加利亚分腿蹲、靠墙静蹲、高脚杯深蹲、杠铃深蹲、前/后/侧向弓步、多方向弓步（模拟上网）、登阶、罗马尼亚硬拉、单腿 RDL、臀桥/臀推、北欧腿弯举、提踵/单腿提踵、胫骨前肌抬起、哥本哈根侧桥。
  - **爆发力/增强式**：深蹲跳、箱跳、分腿跳、侧向跨跳、滑冰跳、团身跳、单腿跳、深跳。
  - **核心**：平板支撑、侧桥、死虫、鸟狗、俄罗斯转体、Pallof 推、药球转体抛、悬垂举腿、伐木劈。
  - **上肢与肩**：俯卧撑、引体向上、哑铃划船、推举、面拉、弹力带肩外旋、YTW、肩胛俯卧撑、药球过头砸。
  - **前臂与手腕**：腕弯举、反向腕弯举、前臂旋前/旋后、桡尺偏、握力训练。
  - **步法与敏捷**：六点步法影子、分腿启动步、绳梯、折返跑、T 字/米字跑。
  - **体能**：跳绳、间歇冲刺、波比跳。
  - **柔韧与灵活性**：髋屈肌拉伸、胸椎旋转、睡眠者拉伸、小腿/腘绳肌拉伸、踝关节灵活性、世界最伟大拉伸。
- 列表页：按类别/难度/器械/目标肌肉筛选，搜索。
- 详情页：**自绘 SVG 动作示意动画**（参数化人形 + 关节关键点起止姿态插值，可暂停/逐帧查看，目标肌肉在人形上着色）、迷你肌肉图标出主/次要肌群（可点击跳到肌肉）、步骤、要点、常见错误、进阶/退阶、推荐量、羽毛球收益、B 站内嵌视频（懒加载，点击后才加载 iframe）、参考来源、"加入我的计划"。

## 8. 训练计划与打卡模块
- **预设计划**（约 8 套）：覆盖入门/进阶/高阶 × 短时（~20 分钟）/中时（~40 分钟）/长时（~60 分钟），例如"入门下肢稳定 4 周""进阶步法爆发 8 周""高阶全面体能 8 周""每日 15 分钟护膝护肩"等；计划页可按难度与时长筛选。
- **自定义计划**：从动作库选动作，设置每周训练日、组数/次数/时长/休息，可复制预设计划再修改。
- **开始计划** → 生成日程；**今日训练页**逐个动作勾选完成，内置组间休息倒计时；完成后记录 RPE 和备注。
- **统计**：月历热力图、连续打卡天数、计划完成率、各肌群每周训练量分布（可在肌肉图上以热度着色展示）。
- **数据**：localStorage 持久化（带 schema 版本），设置页支持 JSON 导出/导入（校验格式、合并或覆盖）、清空数据。

## 9. 通用体验
- 响应式：移动端底部 Tab 导航，桌面端顶部导航 + 侧栏。
- 暗黑模式：跟随系统 / 手动切换，持久化。
- 全局搜索：`⌘K` / `Ctrl+K` 唤起，Fuse.js 同时搜索肌肉、动作、计划、技术（支持中英文名）。
- PWA：多文件版可离线、可安装；单 HTML 版本身离线可用（视频除外）。

## 10. 测试与验收
- vitest 数据完整性测试：所有引用的 muscleId/exerciseId/techniqueId 都存在；每个肌肉在 SVG 中有对应区块；每个动作有姿态、步骤、至少一个来源；预设计划时长估算与标注一致。
- 手动验收：`pnpm dev` 检查三视角切换与点击弹窗、动作动画、打卡流程、导入导出、暗黑模式、移动端布局；`pnpm build` 与 `pnpm build:single` 均成功，单 HTML 直接双击打开可正常使用（Hash 路由、无外部资源请求、localStorage 正常）；`pnpm lint` 零错误。

## 11. 实施顺序
1. 初始化工程、ESLint/VS Code/Git 钩子/CI 配置、两种构建模式跑通。
2. 布局、路由、主题、UI 基础组件。
3. 联网检索资料，编写肌肉/技术/动作数据与参考文献。
4. 三视角肌肉 SVG 与交互。
5. 参数化人形与动作姿态动画、动作库页面、B 站视频核实与嵌入。
6. 计划、打卡、统计、导入导出。
7. 全局搜索、PWA、测试、README，最终构建验证。

## 假设
- 不初始化远程仓库、不提交代码；只执行 `git init` 并准备好配置，提交与推送由你来做。
- 自绘人体与动作图为风格化示意（非医学解剖插画），解剖位置以参考资料为准。
- 内容量较大，动作数据会尽量完整，但每条均以可核实来源为前提；无可靠来源的条目宁缺毋滥。
